Rectangular Approximation Method

You can approximate the definite integral of a function y = f(x) over an interval [a,b] using rectangular approximation methods.

The interval [a,b] is divided into n subintervals of equal length. Over each subinterval a rectangle of the specified height is drawn. The sum of the areas of the n rectangles approximates the integral.

Left sum: Uses the function value at the left endpoint of each subinterval for the height of the rectangle.

Mid sum: Uses the function value at the midpoint of each subinterval for the height of the rectangle.

Right sum: Uses the function value at the right endpoint of each subinterval for the height of the rectangle.

To use the program, enter your function into Y1 first. Then enter this program and store it in your calculator.
